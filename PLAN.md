# Game : DoppleRender

The purpose of the game is to present 10 pairs of 2 images to the end-user. For each pair, one image is real, the other one is AI-generated.

# index.html

- Main structure of the main page.

# script.js

- Game logic.
    - The game is made of 10 pairs each. Each pair is displayed at once, asking the player to select if it is real or AI.
    - The player has to select 10 images out of the 10 pairs.
    - At the end of the 10 pairs, the game will display a summary of the right/wrong answsers.
    - Then the game offers to replay for a new round.
- Mechanics
    - 
- Replayability
    - The same pair should not appear twice in the same game.
    - The same pair should (ideally) not appear twice as long as all the pairs are not exhausted


# image_mapping.js

- mapping list between the pair's image filename and their UID, to preven cheating (like reading the source code)
- the mapping is generated by `dev/process_pairs.py`

# dev/process_pairs.py

- generates a mapping, using each file to create a UID (unique ID)
- the UID is generated using SHA256 over each image file
- the original images are found in dev/assets/
- each pair is nammed using this pattern : XXX_a.png, XXX_b.png
    - `_a` is always the _real_ image, `_b` is always the _generated_ image
- if there is a hole or missing image (missing increment, or a, or b) throw an error so that I can manually fix it
